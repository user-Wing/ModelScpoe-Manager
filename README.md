# ModelScope Manager 1.0.4

Windows 桌面端 ModelScope 仓库资源管理器，使用官方 `modelscope-hub` Python SDK。

## 使用

双击 `start.bat`。发布目录内已包含 Python 运行环境和依赖，不需要安装 Python 包。

> GitHub 源码仓库不提交约 220 MB 的便携 Python 运行时和本地 `data` 运行数据；完整便携构建包会包含 `runtime`，解压后可直接运行。

1. 在左侧“设置”页面添加一个或多个 ModelScope 账户 Token，并设置默认下载路径；Token 会自动验证用户名并采用设备绑定加密。需要删除、移动和重命名时，在独立的“ModelScope 账户 在线登录”表格中用 `+` 添加账户名称，再点击该行“在线登录”；成功后状态显示“成功”，网页登录信息同样采用设备绑定加密。
2. 返回默认的“资源管理”页面，依次展开“账户 → 模型/数据集”，选择仓库。
3. 右侧采用资源管理器式目录视图；将本地文件或文件夹拖到某个目录上，会立即上传到该目录。
4. 上传、下载进度可在左侧“传输列表”中查看，并可通过上方二级栏切换。
5. “资源搜索”可粘贴其他用户的公开模型或数据集链接，浏览方式与资源管理页面一致，公开资源无需令牌即可读取。

资源管理左侧仓库树包含只读 `Public` 根节点，列出资源搜索成功加载过的公开仓库；这些仓库的文件条目和文件夹大小索引会保存到本地，默认不会在后台重新抓取，点击“更新索引”才会刷新。资源搜索页右上角的“搜索历史”以独立非模态窗口显示已加载仓库和链接。

仓库树用分隔线显示三类来源：`Public`、Token 登录账户和网页登录账户。Public 始终只读；Token 账户支持 SDK 读取、下载和上传，但删除、移动、重命名显示为不可用并提示使用在线登录列表；网页登录账户支持这些文件管理操作。不同类型账户之间可以复制，所有新路径的上传和秒传提交仍统一使用有权访问目标仓库的 Token SDK，不使用受限的网页上传接口。

资源搜索页的文件栏支持 Everything 风格的多条件搜索：空格分隔的每个片段都必须在完整路径中出现，因此可组合目录片段和文件名片段，或组合文件名的前后部分；另支持 `path:`、`name:`、`ext:`、`type:`、引号短语和 `*`/`?` 通配符。名称、类型、真实大小和路径均可通过排序下拉框、升降序按钮或表头排序；状态栏显示当前匹配数和仓库总条目数。

搜索历史支持逐条删除或清空；`Public` 仓库可右键移除或打开网页端，移除会同步删除本地历史、索引、文件夹大小缓存和标签。已验证账户下的仓库仅提供“打开网页端”。

文件或文件夹右键菜单中的“标签”支持多选已有标签或新建标签；标签保存在本地数据库，可在资源管理页顶栏按标签筛选。仓库更新索引后，远端已消失文件对应的本地标签会一并移除。

主窗口使用 PySide6-Fluent-Widgets 的 `FluentWindow`、动画页面栈和 Windows 11 风格导航栏；“设置”固定在左侧栏底部。设置页使用 Fluent 设置卡片、平滑滚动和透明背景，浅色、深色及统一蓝色强调色集中切换。账号、下载、播放、WebDAV 与索引等复杂设置使用标准对齐的可折叠首行，点击右侧箭头再展开详细内容。

“设置 → 个性化”可选择跟随系统、浅色或深色主题，默认跟随系统；主题会在系统颜色方案变化时自动更新。可即时调整全局字号，原生 Qt、Fluent 控件和已加载的 Matplotlib 图表会同步更新。Windows 11 Mica 只通过 FluentWindow 自带的桌面合成路径渲染，Qt 页面保持不透明，避免透明顶层窗口产生滚动残影；GPU 加速开关在下次启动时选择桌面 OpenGL 或软件 OpenGL。限速分时时段的开始和结束时间使用与当前主题一致的输入样式。

上传列表是顺序队列。每个文件或文件夹会保存独立的目标路径，正在上传时仍可继续拖放或选择项目加入队列；新项目会显示“等待”，并在前项完成后继续上传。当前项目支持暂停、恢复和取消：暂停在 SDK 的下一次数据读取边界生效，取消不会删除已完成上传到远端的内容。

资源管理页顶栏提供全盘秒搜，可限定全部仓库、当前账户、当前仓库或当前选中目录，并按视频、图片、文档、压缩包筛选。全部类型不再截断结果；空格分隔的路径或文件名片段采用 AND 匹配，也支持 `path:`、`name:`、`ext:`、`type:`、引号短语和 `*`/`?` 通配符。名称、类型、真实大小、仓库和路径可点击表头排序。搜索直接查询 `manager.sqlite3` 的本地索引，不会在输入时重复访问 ModelScope；双击结果可跳回原仓库文件，右键仍可下载或复制直链。后台仓库索引完成后搜索数据会自动更新。

右上角“更新索引”用于手动完整重建。程序每次启动并读取完账户仓库后自动完整更新一次；之后不会因为普通页面刷新而重复遍历所有仓库。上传、备份和图床写入只把对应仓库标记为待更新，用户停止操作约 5 秒或切换到其他页面后才利用空闲时间刷新。程序隐藏或位于后台时，只处理这些发生变化的仓库；后台检查间隔可在设置中按分钟修改，最小 1 分钟、默认 5 分钟。

文件右键菜单中的“复制直链”会构造不含 Token 的稳定地址：公开仓库使用 `/resolve/master/文件路径`，私有仓库使用 `/api/v1/.../repo?Revision=master&FilePath=文件路径`，并在复制私有链接时明确提示其为 API 形式。文件夹的“复制链接”仍复制对应仓库网页目录链接；私有 API 链接仅对拥有仓库权限的访问者有效。

下载时，在任一仓库目录中右键文件或文件夹，选择“添加到下载队列”，资源会加入“传输列表 → 下载”、自动开始并保存到设置中的默认下载路径。程序内置 aria2-next，支持断点续传、分段下载、暂停、恢复、停止和 SHA-256 校验；停止不会删除已下载内容或断点文件，文件夹会在本地还原目录结构。

ModelScope 当前限制访问令牌执行文件删除，因此资源列表改用独立网页登录会话执行“删除”。每次删除都会提示“此操作不可逆”；文件夹会递归收集全部文件，并按最多 100 个文件合并为一次服务端提交，空目录由 ModelScope 自动移除。批量请求结果不确定时，程序只查询目标目录确认实际残留，再对仍存在的文件回退逐项删除。完成后本地 SQLite 条目、标签和文件夹大小按所选路径增量更新并刷新当前视图，不重新扫描或重写整个仓库索引。Public 和 Token 账户仍显示删除、移动、重命名菜单但为灰色，并分别提示“这是只读”或“请使用在线登录列表执行”。

移动和重命名复用下载、Token SDK 上传及网页删除链路：先按“复制阈值”判断是否继续下载到临时目录，全部新路径上传成功后才允许删除旧文件；任一上传失败时旧文件全部保留。重命名区分大小写并拒绝重命名为自身。网页登录 Cookie 只用于身份、读取、下载和删除，上传始终要求有权访问目标仓库的 Token 账户。

上传和下载均显示总体百分比、速度与预计剩余时间。下载速度直接读取 aria2-next 的实时总速度，不受前面小文件的历史平均值影响。模型仓库中单个超过 50 GB 的文件会在上传前提示并自动跳过。

“设置 → 下载设置 → aria2-next 详细配置”可按小、中、大文件分别设置 HTTP 连接和分段数，默认阈值为 1 MB / 100 MB，分段数为 1 / 32 / 64。大量小文件会自动增加并发下载任务，也可一键恢复默认配置。

同一卡片下方提供上传/下载限速。默认关闭且上下行均不限速；启用后可设置默认 MB/s，并添加多个每天重复的分时时段。时段可跨越午夜，重叠时以列表中最后一条为准。下载任务运行期间会通过 aria2-next 动态更新全局限速，无需暂停；上传使用进程级共享限速器，普通上传、文件夹上传、备份和图床共同遵守当前上传上限。

公开音视频文件的右键菜单提供“用外部播放器打开”。可在设置中添加多个 mpv、PotPlayer 等播放器并自定义名称，右键二级菜单会让用户选择本次使用的播放器。为避免向第三方进程暴露访问令牌，私有仓库文件应先下载后再播放。

设置页支持简体中文与 English 即时切换，语言文本位于 `modelscope_manager/locales` 的 JSON 配置文件中，无需重启程序。关闭窗口时可选择直接退出或最小化到通知区域，并决定是否记住选择；传输过程中退出会再次确认。

“基本设置”中可设置语言、关闭行为和当前 Windows 用户的开机自启。设置页依次按基本设置、个性化、账号设置、下载设置、播放设置、WebDAV 设置、索引和预览排列。所有设置继续写入便携目录的 `QSettings`，主题、字号和语言修改后立即更新界面；图床会按账户记住上次使用的仓库。仓库栏的“紧凑视图”默认关闭，开启后将文件列表行距压缩约 20%，设置会自动保存。

仓库目录读取完成后会自动建立递归缩略图队列：当前打开目录优先，随后按目录深度在用户空闲时逐批处理子目录。超过 100 项的仓库每批最多处理 96 个媒体、并发上限 32，小仓库每批最多 48 个、并发上限 16；用户设置的线程数仍作为实际并发上限。视频会在打开远端输入前快速定位至约 1.5 秒，尽量利用 HTTP Range 减少读取并避开常见的黑屏首帧；缓存缩略图为 320×180。失败格式回退普通文件图标且不会无限重试。

紧凑视图使用明确的勾选框。勾选时左侧仓库栏使用紧凑宽度和行距；取消勾选后左侧宽度由约 270 增至 405，增加 50%，右侧文件列表恢复宽松行距。

## 备份文件夹与保险箱同步

左侧“备份文件夹”可保存多个独立任务，每个任务指定本地文件夹、ModelScope 账户、模型或数据集仓库、远端目标目录、扫描周期和云端同步大小阈值。程序每 30 秒检查一次到期任务，实际执行周期由任务的分钟/小时配置决定；与普通上传下载冲突时会等待下一轮。

- `增量备份（时间戳）`：只上传新增或修改文件，在目标目录下创建 `YYYYMMDD-HHMMSS` 文件夹。
- `同路径覆盖`：把新增或修改文件上传到固定远端路径，同名文件形成新的仓库版本。由于官方 Token API 不支持删除，本地已经删除的文件不会从远端消失，因此该模式不是严格镜像删除。
- 单个达到或超过 50 GB 的文件会明确提示并跳过，不会静默失败。
- “从云端同步到本地”在增量模式下读取最新时间戳目录，在同路径覆盖模式下读取固定目标目录，并通过现有 aria2-next 下载队列恢复相对目录。默认只同步不超过 10 MB 的文件，任务中可修改阈值。

ModelScope 官方建议使用 HTTP SDK 的 `upload_file` / `upload_folder` 接口，并说明 `push_model` 已弃用，因此覆盖模式继续复用现有 HTTP SDK，而不引入额外 Git/Git LFS 环境。远端 Git 版本历史仍由 ModelScope 保存。

## 图床与内置播放器

左侧“图床”可选择账户、仓库和存储路径，拖入、选择或在页面内按 `Ctrl+V` 粘贴常见图片后，会先验证文件确实可读取为图片，再上传至按年月划分的目录，为文件增加随机短前缀避免同名冲突。公开仓库优先保存并复制 `/resolve/master/` 公有直链，私有仓库使用不含 Token 的 API 形式。上传记录和图片缓存位于统一数据目录；双击记录或点击“缓存打开”会优先使用已经安装的本地 PotPlayer。

3FP 及其专用 .NET 运行环境已移除，PotPlayer 也不随程序预装。在“设置 → 播放器”点击“下载并安装 PotPlayer”后，程序会把 `ARXChem/Animations-List` 数据集中的 `! Software/PotPlayer.7z` 加入普通下载队列，由内置 aria2-next 完成断点续传、SHA-256 校验，再调用随程序提供的 7z-zstd 解压到统一数据目录。安装后，远端视频、音频和图片默认通过 PotPlayer 直链打开；私有资源仍通过仅监听 `127.0.0.1` 的内存流转发鉴权和 Range 请求，不产生媒体缓存且 Token 不进入播放器命令行。现有第三方播放器表格保持可用。

通知区域菜单会实时显示 WebDAV 监听状态以及当前上传/下载速度，并可直接开启或关闭监听；原有“显示 ModelScope Manager”和“退出”操作保持不变。

设置页顶部默认启用“禁用鼠标滚轮修改配置选项”，滚轮经过下拉框和数字配置时只滚动页面，不会意外改变数值。aria2-next 阈值和 AList 端口均使用“数字 / 增大 / 减小”按钮。

## AList V3 挂载

管理器内置只依赖 Python 标准库的 WebDAV 网关。在“设置 → WebDAV 设置 → AList V3 挂载”中填写配置后点击“启动”即可；即使没有令牌，网关仍会启动并提供固定根目录和已保存的公共池。AList 后台添加存储时填写：

“启动程序后自动启动监听”默认关闭。启用后，程序下次启动并完成账户仓库加载时会自动开启 WebDAV；关闭该选项仍可通过设置页的“启动/停止”按钮或托盘菜单手动启停。WebDAV 配置字段会自动保存。

WebDAV 启动前会检查端口占用；若当前端口不可用，程序会自动尝试相邻端口并在窗口顶部短暂提示实际使用的端口。

“WebDAV 设置”组顶部固定显示独立“监听端口”卡片，自动切换后的实际端口会立即写回此处和下方 WebDAV 地址。

- 驱动：`WebDAV`
- 厂商：`其他`
- 地址：使用设置页显示的 WebDAV URL；同一台电脑通常为 `http://127.0.0.1:9867/`
- 根文件夹路径：填写 `/` 或留空
- 用户名和密码：使用设置页中显示的值
- AList 位于 Docker 时，可使用 `http://host.docker.internal:9867/`，或选择局域网监听并使用设置页显示的局域网 IP

WebDAV 根目录始终包含 `models`、`datasets`、`public`，其中个人仓库会合并已验证账户的可用仓库：

- `models/账户/仓库`：当前令牌拥有的模型仓库；没有令牌时为空。
- `datasets/账户/仓库`：当前令牌拥有的数据集仓库；没有令牌时为空。
- `public/账户@仓库 [类型]`：资源搜索页面成功加载过的每个公开仓库都会成为一个独立挂载目录；记录保存在程序目录的 `data/public_pools.json`，重启后会自动恢复。

目录列举和读取由 ModelScope SDK/直链完成，AList 上传会转交 SDK 写入个人仓库，公共池只读。由于 ModelScope 官方访问令牌目前不允许删除，WebDAV 会拒绝删除、重命名、移动和复制操作。

程序加载后会在后台递归索引各仓库文件列表，把每个目录（包括所有后代内容）的聚合大小写入统一数据库 `data/manager.sqlite3`。资源目录中的文件夹大小显示最近一次索引值，不会为了打开目录而重新计算；点击“更新索引”或后台索引完成后才显示最新准确值。WebDAV 返回目录属性时直接读取该索引。

`dial tcp ... connectex` 表示 AList 尚未连接到网关，发生在 WebDAV 根目录读取之前。同机 AList 使用 `127.0.0.1`；其他设备必须选择“局域网 / Docker”监听，并在需要时允许程序通过 Windows Defender 防火墙。

“新建文件夹”创建的是上传目标路径。Git 仓库不能保存空目录，因此首次向其中上传内容后，该目录才会显示在仓库中。

用户配置统一保存在程序目录的 `data` 文件夹：`settings.ini` 保存普通设置，`device.id` 保存设备绑定标识，`public_pools.json` 保存公共资源池，`manager.sqlite3` 保存账户元数据、DPAPI 加密 Token、仓库缓存、文件元数据结构和目录大小索引。旧版注册表设置、单账户 Token 与 `folder_sizes.sqlite3` 会在首次启动时自动迁移。

令牌同时与设备标识绑定。把整个程序目录复制到另一台设备后，复制品无法解开原设备保护的 `device.id`，会生成新的设备标识并立即清除复制品中的令牌；原设备目录中的令牌不受影响。

## 开发运行

仓库存在便携 `runtime` 时，`main.py` 会优先使用其中的 PySide6-Fluent-Widgets，避免误载用户目录中使用其他 Qt 绑定的同名 `qfluentwidgets` 包。

```powershell
py -3.12 main.py
```
